# rust-practice
日々の日誌として使用するアプリケーションを作成する。
シンプルな要求仕様となるのでRustを覚えながら作成していく。

## 技術選定
**言語**
Rust

*選定理由*
関数型プログラミングを理解したいと考えたため。
Rust製のプロダクトが多く生まれているので、OSSを読めるようにしたいのでRustを覚えたかったため。

**フレームワーク**
topcoat

*選定理由*
フルスタックフレームワークを利用した場合に、どのように作成するのが望ましいのか吟味したいと考えたため。
以前のプロジェクトでJava/SWTを用いた業務システムを開発したときに自分であればどういう構成にするか考えたが作成はしていなかったので、
実際に作ってみるという試みを行うからである。

**ORM**
SeaORM

*選定理由*
公式ドキュメントが豊富で読みやすいと感じたため、トラブルシューティングを行いやすいと思われるので採用。
またActiveRecordについても触れられる機会となるので採用した。

### Infra
#### Google Cloud
実際の運用では使用しない。
Google Cloudの試験を受けるので、実際に動くものを作成してみる練習台になるため。
あくまで試験に向けたサンドボックスに近いと考えている。

**Cloud SQL**
小規模でスケールすることはない想定のため、Cloud SQLを選定。
Entity, ORM, Migrationの実施用に使用する。

実際の運用ではこちらを使用する。WASM上に動かすように対応が必要
